📊 ## Portfolio Optimization Dashboard

This project is an interactive web application built with Streamlit that allows users to analyze, simulate, and optimize investment portfolios** using historical financial data and modern portfolio theory.

🔧 # Features

* Upload or fetch financial asset data
* Compute expected returns, volatility, and Sharpe ratios
* Visualize efficient frontiers and capital market lines
* Perform Monte Carlo simulations to identify optimal asset allocations
* Use optimization algorithms (e.g. mean-variance optimization) to find the best portfolio based on user-defined criteria (max return, min risk, etc.)
* Export results and charts as Excel or PDF reports

🧠 # Technologies Used

* `Python` | `Pandas` | `NumPy` | `Matplotlib` | `Seaborn`
* `scipy.optimize` for portfolio optimization
* `yfinance` for retrieving financial data
* `Streamlit` for creating the interactive UI
* `OpenPyXL` / `xlsxwriter` for report export

🚀 # Purpose

This tool was developed as part of a personal project to deepen my understanding of portfolio theory, data-driven investment strategies, and the use of Python in financial decision-making.
